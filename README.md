# Personal Mini-Toolkit (PLP Python Week 8 Final Project)

## Description
The **Personal Mini-Toolkit** is a versatile Python command-line application that aggregates three interactive utility tools into a single menu-driven program:
1. **Simple Calculator**: Performs core arithmetic operations (+, -, *, /) with safety checks for invalid inputs and zero division.
2. **To-Do List Manager**: Maintains a dynamic list of daily tasks that users can view, add to, or delete during execution.
3. **Number Guessing Game**: An interactive game generating a random number between 1 and 20, providing real-time feedback until the correct number is found.

## How to Run the Program
1. Ensure Python 3 is installed on your computer.
2. Clone this repository or download the files.
3. Open a terminal/command prompt in the project directory.
4. Run the script using:
   ```bash
   python toolkit.py
